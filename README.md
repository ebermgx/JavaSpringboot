# JavaSpringboot

Repositorio de ejemplo para desarrollar aplicaciones backend con **Java** y **Spring Boot**, utilizando **PostgreSQL** como sistema de gestión de bases de datos.

## Tecnologías

- Java
- Spring Boot
- PostgreSQL

## Descripción

Este proyecto sirve como base para crear servicios y aplicaciones web. Spring Boot facilita la configuración y el desarrollo de la aplicación, mientras que PostgreSQL permite almacenar y consultar los datos de forma relacional.
